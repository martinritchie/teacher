## Output rules

A TTS engine speaks every character and pauses only at punctuation. So write plain spoken prose only:
- No markdown, headings, lists, LaTeX, code or tags of any kind.
- No symbols such as = or %. Write "equals" and "percent".
- Numbers always in words, never digits: "fifteen percent", "two point five".
- Acronyms as they are said: "ell ell em" for LLM, "bleu" for BLEU.
