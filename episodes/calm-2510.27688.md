The efficiency of large language models is fundamentally limited by their sequential, token by token generation process. We argue that overcoming this bottleneck requires a new design axis for large language model scaling increasing the semantic bandwidth of each generative step. To this end we introduce Continuous Autoregressive Language Models a paradigm shift from discrete next token prediction to continuous next vector prediction. CALM uses a high fidelity autoencoder to compress a chunk of K tokens into a single continuous vector from which the original tokens can be reconstructed with over ninety nine point nine percent accuracy. This allows us to model language as a sequence of continuous vectors instead of discrete tokens which reduces the number of generative steps by a factor of K. The paradigm shift necessitates a new modeling toolkit therefore we develop a comprehensive likelihood free framework that enables robust training evaluation and controllable sampling in the continuous domain. Experiments show that CALM significantly improves the performance compute trade off achieving the performance of strong discrete baselines at a significantly lower computational cost. More importantly these findings establish next vector prediction as a powerful and scalable pathway towards ultra efficient language models.

Large language models generate text one token at a time. Each token is a small unit like a word or part of a word. This process is slow because the model has to make a prediction for every single token. Researchers have tried to make this more efficient by using bigger tokens, like groups of words, to reduce the number of steps. But even with these improvements, the amount of information each token can carry is limited. This is because the number of possible tokens grows exponentially if you want to carry more information, which makes the model harder to train and use. The current approach has hit a wall in terms of efficiency, so new ideas are needed to break through this barrier.

The autoencoder needs to compress groups of tokens into a single vector without losing important information. Previous methods focused on improving the size of tokens but couldn't scale the amount of information each token could carry without making the model too complex. The authors designed a lightweight autoencoder that compresses K tokens into a single continuous vector. This vector can be used to reconstruct the original tokens with over ninety nine point nine percent accuracy, which is a major improvement in fidelity.

The model needs to generate text in the continuous vector space without relying on traditional probability calculations. Traditional models use probability distributions like softmax, but these don't work well in the continuous domain because there's no finite vocabulary to choose from. The authors introduced a likelihood-free framework that uses an energy-based model instead of softmax. This allows the model to generate vectors in a single step without the need for iterative sampling, which makes it much faster.

Evaluating the model's performance in the continuous domain is challenging without traditional metrics like perplexity. Standard evaluation metrics rely on explicit probability distributions, which are not available in the continuous setting. The authors created a new evaluation metric called BrierLM based on the Brier score. This metric doesn't require knowing the full probability distribution and can be estimated by sampling from the model, making it ideal for continuous language models.

Controlling the generation process with temperature sampling is difficult in the continuous domain. Temperature sampling adjusts the randomness of the output by manipulating the probability distribution, but this is not directly applicable when no distribution is available. The authors developed a new sampling algorithm that mimics temperature sampling in the continuous space. This algorithm can draw samples from the exact temperature distribution and has an efficient batch approximation, making it practical for real-world use.

Here is how it works. The method has five pieces: the autoencoder, the energy-based generative head, the energy loss, BrierLM and temperature sampling algorithm.

The autoencoder takes a sequence of K tokens and maps them into a single continuous vector. It starts by turning each token into an embedding using a position-wise feed-forward network. These embeddings are then flattened into a single vector of size Kd. This is compressed with a linear layer to reduce it to size d. The compressed vector goes through another feed-forward network and a linear projection to create the latent vector z. Instead of outputting z directly, the encoder outputs the mean and standard deviation of a diagonal Gaussian distribution from which z is sampled during training.

The decoder mirrors the encoder. It transforms z using a linear layer and an FFN to get a d-dimensional hidden state. This is expanded to Kd dimensions and reshaped into K hidden states. Each of these states goes through another FFN, then a projection to vocabulary logits using tied embeddings. Tokens are reconstructed by taking the argmax of these logits.

The autoencoder is trained to minimize the cross-entropy loss across all K tokens. This ensures the reconstructed tokens match the original sequence. To make the latent space smooth and robust, the encoder outputs a Gaussian distribution instead of a fixed vector. A KL divergence loss is added to encourage the distribution to match a standard normal prior. This balances reconstruction accuracy and smoothness with a small weight.

To prevent some latent dimensions from collapsing, each dimension's KL loss is clipped to a minimum threshold. Dropout is used during training: fifteen percent of tokens are randomly masked, forcing the encoder to infer them from context. Dropout is also applied to the latent vector before passing it to the decoder, encouraging redundancy. These techniques ensure the latent vector is both accurate and robust, with a dimension of one hundred and twenty-eight for K = four tokens.

The energy-based generative head takes two inputs: the transformer's hidden state and a random noise vector. The noise vector has each dimension drawn from a uniform distribution between negative zero point five and zero point five. Both inputs are projected to match the transformer's hidden dimension using separate linear layers.

The head uses a stack of residual MLP blocks to refine the noise vector. Each block starts by fusing the current noise vector with the hidden state through two linear layers. Then a SwiGLU layer is applied, with an intermediate dimension matching the transformer's hidden size. The block's output is added to its input through a residual connection. This process repeats for each block in the stack.

After all blocks, the refined vector is projected to the target dimension using a final linear layer. This produces the continuous vector output. The stack has about six times the square of the hidden dimension in parameters. The number of blocks is set to a quarter of the transformer's layers, keeping the head's parameters to about ten percent of the total model.

The output vector is used to predict the next chunk of tokens. The head generates vectors in a single step, avoiding iterative sampling. This makes the generation process faster and more efficient. The noise vector introduces randomness, allowing the model to explore different possibilities during sampling.

The energy loss trains the model by comparing generated vectors with target samples using distances between them. It starts by drawing eight candidate samples from the generative head at each step. Then it draws one hundred target samples from the conditional Gaussian posterior of the autoencoder. For each candidate, it calculates the distance to every target and averages them all. It also calculates the average distance between every pair of candidates. The energy loss combines these two parts: twice the average distance between targets and candidates, minus the average distance between candidates. This gives a single number that measures how well the generated samples match the targets while keeping them diverse. The model uses this number to adjust its weights during training. The number of candidate samples is small to keep training efficient, while the number of target samples is large to reduce the loss’s variance. This method works without needing probability distributions, making it flexible for different model designs. The loss is estimated using Monte Carlo sampling over all steps, giving an overall measure of how well the model is learning.

BrierLM measures how well the model predicts and calibrates its outputs without needing probability distributions. It uses generated text samples and a reference text to compute a score. For each n-gram in the reference, the method draws two independent samples from the model. It checks if each sample matches the reference and if the two samples match each other. It adds the match counts and subtracts the overlap count to estimate the Brier score for that n-gram. This is done for n-grams of length one to four. The Brier-n scores for each length are multiplied together, then the fourth root is taken, and the result is scaled to a one hundred-point range. A perfect score of one hundred means the model is both accurate and well-calibrated. The method works by treating each n-gram as a single outcome, making it easier to compare with traditional metrics. It uses only model samples, so it fits likelihood-free models like CALM. The geometric mean ensures all n-gram lengths contribute equally. This score helps evaluate how well the model predicts and how confident it is in its predictions, without relying on probabilities.

The temperature sampling algorithm adjusts output diversity by sampling from batches of generated vectors using a two-stage rejection process and a fallback mechanism. It takes generated vectors from the energy-based generative head, a temperature parameter, and a batch size as inputs.

First, it splits the temperature T into an integer part n and a fractional part. Then it draws a batch of samples from the generative head. It counts how many times each sample appears in the batch. For each sample that appears at least n times, it calculates the number of combinations using the binomial coefficient. If no samples meet this count, it reduces the required count step by step until it finds a valid set. It selects samples that meet the current count threshold and weights them by their combination counts. It then samples an output from the valid set, with probabilities proportional to these weights.

For the fractional part, it uses the Bernoulli Factory algorithm to simulate a biased coin flip with a success probability equal to the original probability of the sample raised to the power of the fractional part. A sample is accepted only if both the integer and fractional stages succeed. If not, the process restarts.

This approach works even when no explicit probability distribution is available. The algorithm ensures that the output distribution matches the target temperature. It uses a batch of samples to approximate the distribution efficiently, reducing the need for repeated rejections. The batch size controls the trade-off between accuracy and computational efficiency. The fallback mechanism ensures the algorithm always produces a sample, even when no samples meet the initial count requirement.
