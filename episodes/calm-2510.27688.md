The efficiency of large language models is fundamentally limited by their sequential, token by token generation process. We argue that overcoming this bottleneck requires a new design axis for large language model scaling increasing the semantic bandwidth of each generative step. To this end we introduce continuous autoregressive language models a paradigm shift from discrete next token prediction to continuous next vector prediction. Continuous autoregressive language models uses a high fidelity autoencoder to compress a chunk of K tokens into a single continuous vector from which the original tokens can be reconstructed with over ninety nine point nine percent accuracy. This allows us to model language as a sequence of continuous vectors instead of discrete tokens which reduces the number of generative steps by a factor of K. The paradigm shift necessitates a new modeling toolkit therefore we develop a comprehensive likelihood free framework that enables robust training evaluation and controllable sampling in the continuous domain. Experiments show that continuous autoregressive language models significantly improves the performance compute trade off achieving the performance of strong discrete baselines at a significantly lower computational cost. More importantly these findings establish next vector prediction as a powerful and scalable pathway towards ultra efficient language models.

Large language models generate text one token at a time, which is slow and inefficient. Each token is a discrete unit from a fixed vocabulary, and predicting one at a time limits how much information can be processed in each step. Researchers have tried increasing the information density by using bigger tokens, like phrases instead of single words, but this runs into a problem: the vocabulary size needed to represent more information grows exponentially, making the model too slow and complex. This means the way these models work is stuck in a bottleneck, where even though the models themselves are getting more powerful, the task they're doing—predicting one token at a time—hasn't changed much. This creates a mismatch between the model's potential and its actual performance.

The way language models generate text is too slow because they predict one token at a time. Most models use discrete tokens, and to increase information density, they'd need to expand their vocabulary exponentially, which is not practical. The authors introduce a new approach that compresses a group of K tokens into a single continuous vector. This reduces the number of steps needed to generate text by a factor of K, making the process much faster.

Models trained on continuous vectors need a new way to generate and evaluate language without relying on traditional probability distributions. Standard methods like softmax can't work in the continuous domain because there's no finite vocabulary to choose from. The authors develop a likelihood-free framework using an energy-based model that can generate continuous vectors in a single step, avoiding the need for complex probability calculations.

Evaluating how well a continuous model works is tricky because traditional metrics like perplexity don't apply. Traditional evaluation methods depend on explicit probabilities, which are hard to compute in the continuous domain. The authors create a new metric called BrierLM, based on the Brier score, that can fairly compare continuous models without needing probabilities. It's easy to calculate using samples from the model itself.

Controlling the creativity or randomness of a continuous model is difficult without a probability distribution. Standard temperature sampling methods rely on manipulating probabilities, which aren't available in the continuous domain. The authors introduce a new sampling algorithm that can adjust the randomness of the model's output without needing probabilities, allowing for controlled generation in the continuous space.

Here is how it works. The method has five pieces: the high-fidelity autoencoder, the energy-based generative head, the energy loss function, the BrierLM evaluation metric and the temperature sampling algorithm.

The high-fidelity autoencoder takes a sequence of K discrete tokens and compresses them into a single continuous vector. It starts by mapping each token to an embedding using a position-wise feed-forward network. These embeddings are then flattened and compressed into a d-dimensional representation with a linear layer. Next, this is passed through another feed-forward network and a linear projection to produce an l-dimensional latent vector.

To make the latent space smooth and structured, the encoder outputs parameters for a diagonal Gaussian distribution, mu and sigma, instead of a fixed vector. A latent vector is then sampled from this distribution. This introduces randomness and helps avoid brittle representations. The model also adds a KL divergence loss to encourage the latent distribution to stay close to a standard normal prior. A small weight, beta equals one thousandth, balances this regularization with the reconstruction loss.

To prevent some latent dimensions from collapsing into pure noise, the model clips the KL loss for each dimension below a threshold of half. This ensures all dimensions contribute meaningfully to reconstruction. During training, dropout with a rate of fifteen percent is applied to the latent vector and to the input tokens. This forces the model to learn robust, redundant representations and improves its ability to infer missing tokens from context.

The decoder mirrors the encoder. It transforms the latent vector through a linear layer and feed-forward network, expanding it to Kd dimensions and reshaping it into K hidden states. Each state is passed through another feed-forward network and projected to vocabulary logits using the tied input embedding matrix. Finally, the tokens are reconstructed by taking the argmax of these logits. This process achieves over ninety nine point nine percent accuracy in reconstructing the original tokens. The autoencoder is lightweight and efficient, with a hidden dimension of five hundred and twelve and a latent dimension of one hundred and twenty eight for K equals four tokens.

The energy-based generative head takes two inputs: the transformer's hidden state, which is a vector in d dimensions, and a random noise vector. This noise vector has uniform values between negative zero point five and positive zero point five. Both inputs are first passed through separate linear layers to match the hidden dimension d.

The noise vector starts as epsilon zero. Then, for each of L residual MLP blocks, the current noise representation is combined with the hidden state using two linear layers. A SwiGLU activation follows, with an intermediate dimension of d. The output of this block is added back to its input through a residual connection. This process refines the noise vector step by step.

After all blocks, the final refined representation is passed through a linear layer to project it into the target dimension l. This gives the output vector z i, which is a continuous vector representing the generated output for the current step.

Each MLP block has about six times d squared parameters. The number of blocks is set to a quarter of the transformer layers. This keeps the generative head lightweight, with only about ten percent of the total model parameters.

The head generates a continuous vector in a single step, avoiding the need for iterative sampling. This makes it efficient and suitable for the continuous autoregressive approach.

The energy loss function trains the model without using probability distributions. It compares distances between generated samples and target samples instead of calculating probabilities. To use it, you need two sets of samples: N generated from the model and M from the conditional Gaussian posterior.

First, draw N candidate samples from the generative head. These are the model’s predictions. Then, draw M target samples from the conditional Gaussian posterior distribution, which represents the true data.

Next, calculate the pairwise distances between all generated samples and all target samples using the squared distance measure. This measures how close the model’s predictions are to the true data. Also, calculate the pairwise distances between all generated samples using the same squared distance measure. This checks how diverse the model’s predictions are.

The energy loss is the difference between twice the average distance between generated and target samples and the average distance between generated samples. This ensures the model learns both accuracy and diversity.

To approximate this, use Monte Carlo estimation. Set N to eight generated samples and M to one hundred target samples. This balances training efficiency with variance reduction.

The energy loss function updates the model parameters to minimize this loss. It avoids the need for complex probability calculations, making training feasible in the continuous domain. The exponent alpha is one, which is standard for this setup.

This method ensures the model’s predictive distribution aligns with the true data distribution. It’s a flexible and efficient way to train the generative head without relying on likelihoods.

The BrierLM evaluation metric compares model-generated samples with true data samples to measure how well the model predicts without using probabilities. For each n-gram length from one to four, it first checks how often two generated samples match exactly. This gives the collision probability, which estimates the sum of squared probabilities in the Brier score formula. Then, it checks how often a generated sample matches a true sample, estimating P(y), the probability of the true outcome. The Brier score for each n-gram is calculated as twice the match rate between generated and true samples, minus the collision rate between generated samples. These scores are averaged using a geometric mean across all n-gram lengths. Finally, the result is multiplied by 100 to scale it to a 0-100 range. The metric uses only model samples and true samples as inputs, avoiding any need for explicit probabilities. It rewards models that both match the true data and capture uncertainty by balancing accuracy and collision rates. This makes BrierLM a fair and reliable way to evaluate continuous models, ensuring they are both accurate and well-calibrated.

The temperature sampling algorithm adjusts how varied or focused the model's output is. It uses a base sampler, a target temperature T, and a batch size N. First, it draws N samples from the base distribution. Then, it splits the temperature T into an integer part and a fractional part. The integer part comes from taking the floor of 1 divided by T. For this part, it tries to draw n identical samples, rejecting any set that doesn’t match and restarting if needed. All n samples must be exactly the same for this step to succeed.

For the fractional part, it uses a Bernoulli Factory to simulate a biased coin flip. This process indirectly uses the likelihood of each sample raised to the fractional power without directly accessing the probability. Only samples that pass both steps are accepted.

At low temperatures, like when T equals 1 divided by n, the algorithm draws a batch of N samples and counts how often each sample appears. It looks for samples that appear at least n times, starting with the target n and reducing the count if needed. For each candidate, it calculates how many ways it can be chosen from the batch using a binomial coefficient as the weight. It then selects a sample based on these weights. If no valid candidates are found, it lowers the matching requirement until it finds some. This approach improves efficiency by using a batch of samples instead of requiring exact repetitions. The output follows a distribution that matches the desired temperature setting.
