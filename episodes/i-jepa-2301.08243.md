This paper demonstrates an approach for learning highly semantic image representations without relying on hand crafted data augmentations. We introduce the Image based Joint Embedding Predictive Architecture, a non generative approach for self supervised learning from images. The idea behind I J E P A is simple. From a single context block, predict the representations of various target blocks in the same image. A core design choice to guide I J E P A towards producing semantic representations is the masking strategy. Specifically, it is crucial to sample target blocks with sufficiently large scale semantic, and to use a sufficiently informative spatially distributed context block. Empirically, when combined with Vision Transformers, we find I J E P A to be highly scalable. For instance, we train a ViT Huge fourteen on ImageNet using sixteen A one zero zero GPUs in under seventy two hours to achieve strong downstream performance across a wide range of tasks, from linear classification to object counting and depth prediction.

In self-supervised learning for computer vision, there are two main approaches: invariance-based methods and generative methods. Invariance-based methods train models to produce similar embeddings for different views of the same image, like slightly altered versions made with things like cropping or changing colors. These can create strong semantic representations, but they often introduce biases that might not work well for different tasks. Generative methods, on the other hand, try to reconstruct parts of an image that have been hidden or corrupted, like filling in missing pieces. These are easier to use across different types of data, but the representations they learn are usually less semantic and need more fine-tuning to be useful for tasks like classification.

Existing methods for self-supervised learning either rely on hand-crafted data augmentations or produce less semantic representations that need extra fine-tuning. Invariance-based methods use hand-crafted augmentations to create different views of the same image, but this can lead to biases that don't work well for all tasks. Generative methods, like masked reconstruction, produce less semantic representations and require more adaptation for downstream tasks. I-JEPA learns semantic image representations without using hand-crafted data augmentations by predicting representations of target blocks in an image from a context block, which avoids the need for view-specific transformations and leads to more generalizable features.

Most self-supervised methods either focus on pixel-level reconstruction or rely on view invariances, which can limit their ability to learn high-level semantic features. Generative methods reconstruct images at the pixel or token level, which can lead to less semantic representations. Invariance-based methods focus on making embeddings similar across different views of the same image, but this can limit the model's ability to learn high-level features. I-JEPA predicts in an abstract representation space rather than at the pixel level, which allows the model to focus on learning semantic features without being distracted by unnecessary details.

Many self-supervised methods require extensive computational resources and are not easily scalable. Previous methods for pretraining large vision transformers require a lot of compute time and resources, which limits their practical use. I-JEPA is more efficient and scalable, achieving strong results on ImageNet with less than twelve hundred GPU hours, which is significantly faster and more efficient than other methods like MAE or iBOT.

Here is how it works. The method has seven pieces: context and target block sampling, encoder architectures, mask tokens generation, predictor mechanism, representation space loss calculation, multi-block masking strategy and training procedure.

Start with the image. Split it into non-overlapping patches. Feed these patches through the target encoder to get patch-level representations. Now, randomly pick four target blocks from these representations. Each block has a scale between zero point one five and zero point two and an aspect ratio between zero point seven five and one point five. Blocks can overlap. Then, sample a single context block from the image. This block has a scale between zero point eight five and one and a square shape. Remove any patches in this block that overlap with the target blocks. The result is a context block with non-overlapping patches and the four target blocks from the target encoder. The context block is sparse but informative, while the target blocks are semantically rich. This setup ensures the model learns to predict high-level features from abstract representations rather than pixel details.

The encoder architectures process image patches into abstract representations using Vision Transformer layers. Both the context encoder and target encoder use the same structure: self-attention followed by multi-layer perceptrons. The context encoder processes masked regions, while the target encoder handles non-overlapping patches. For the context encoder, overlapping regions from sampled blocks are removed before encoding. The target encoder encodes non-overlapping patches directly. Both output contextualized embeddings for each patch. The context encoder's output feeds into the predictor, and the target encoder's output provides the target representations for the loss. The target encoder's parameters are updated using an exponential moving average of the context encoder's weights, set to zero point nine nine nine nine. This design ensures stable training and focuses learning on semantic features.

The mask tokens are created by starting with a single shared learnable vector. For each target block position, positional embeddings are added to this vector. These embeddings encode where each target block is located in the image. The result is a set of mask tokens, one for each patch in the target block. Each mask token carries positional information about its specific location. This helps the predictor understand where it needs to focus when making predictions. The mask tokens are used as inputs to the predictor, along with the context encoder output. This setup allows the model to learn the relationship between context and target block positions. The mask tokens are generated once per target block during training. Their design ensures the predictor can accurately locate and predict representations for each target block.

For each target block, take the context encoder output and the mask tokens specific to that block's patches. Pass these through the predictor's transformer layers to generate predicted patch-level representations for each patch in the target block. The predictor uses the context encoder's output as a reference and the mask tokens to guide where to focus. Each mask token has a unique position in the image, so the predictor knows exactly which patches it needs to predict. The transformer layers inside the predictor process this information step by step, combining the context and positional clues to form predictions. After processing, the predictor outputs predicted representations for all patches in the target block. These predictions are then compared to the actual representations from the target encoder using the representation space loss. The predictor is trained to minimize this loss, making its predictions as close as possible to the true values. This process happens separately for each of the four target blocks, with each having its own mask tokens and context information. The predictor mechanism is key to learning semantic representations without needing to reconstruct pixels directly.

For each target block, calculate the distance between the predicted patch-level representation and the actual patch-level representation. Use the squared difference for each patch in the block. Then, average these squared differences across all patches in all target blocks. This gives the overall representation space loss, which tells us how well the model is learning to predict semantic features instead of pixel details. The loss is computed entirely in the representation space, which helps the model focus on high-level features. This approach avoids the need to reconstruct individual pixels, making the learning process more efficient. The loss value guides the training by pushing the model to improve its predictions over time.

The multi-block masking strategy samples four target blocks per image. Each has a random aspect ratio between three quarters and one and a half, and a scale between fifteen and twenty percent of the image. These blocks are chosen to capture semantic features. Then, one context block is sampled with a scale between eighty five and one hundred percent, and a square shape. This block is made non-overlapping with the target blocks to ensure it contains useful spatial information. The mask is applied to the target encoder output, not the input patches. This ensures the targets are high-level representations. The context block is processed by the context encoder to get its representation. These steps guide the model to focus on semantic features rather than pixel details. The strategy helps the model learn generalizable features efficiently.

The training procedure coordinates all components by sampling image regions, encoding them, predicting target block representations, calculating loss, and updating the target encoder using an exponential moving average of the context encoder parameters. Start by sampling a single context block from the image with a scale between eighty five percent and one hundred percent and a unit aspect ratio. Remove any overlapping target blocks to ensure a non-trivial prediction task. Encode the context block using the context encoder to get patch-level representations. Next, sample four target blocks with a scale between fifteen percent and twenty percent and an aspect ratio between seventy five percent and one hundred fifty percent. Encode these target blocks with the target encoder to get their patch-level representations. For each target block, input the context encoder output and mask tokens with positional embeddings into the predictor to generate predicted representations. Calculate the representation space loss as the average distance between predicted and actual target block representations across all patches. Update the target encoder parameters using an exponential moving average of the context encoder parameters with a weight of ninety nine point nine nine percent. Repeat this for all training examples. This process ensures the model learns semantic representations efficiently without relying on hand-crafted data augmentations.
