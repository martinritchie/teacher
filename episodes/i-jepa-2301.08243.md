## Introduction

This work introduces a new way to teach machines to understand images without needing human-designed tricks. The method is called I-JEPA, and it lets models learn rich, meaningful image features on their own. The basic idea is to have the model look at one part of an image and then predict what other parts look like. To guide this process toward understanding the bigger picture, the researchers carefully choose which parts of the image to focus on. They found that using this approach with a type of model called Vision Transformers leads to impressive results. In one example, they trained a large version of this model on a major image dataset in less than three days using a cluster of powerful GPUs, and it performed well on a variety of tasks like identifying objects, counting them, and even predicting depth.

## Contributions

In computer vision, there are two main ways to teach machines to understand images without labels. One approach focuses on making the model insensitive to changes in the image, like differences in color or lighting, by training it to produce similar outputs for different views of the same image. These views are usually created using human-designed tricks like cropping or changing colors. While this can lead to strong representations, it can also introduce biases that don't work well for all tasks. The other approach is to teach the model to predict missing parts of the image, like filling in blank spots. This method doesn't rely as much on human-designed tricks and can work across different types of data, but the representations it learns are usually less detailed and need more tuning to perform well on complex tasks. Both methods have their strengths and weaknesses, and researchers are always looking for better ways to learn meaningful image features without relying on human-designed tricks.

Teaching machines to understand images without using human-designed tricks is difficult because existing methods either introduce biases or learn less detailed features. Most methods rely on either making the model insensitive to changes in the image or predicting missing parts at the pixel level, which can be slow and less effective for complex tasks. I-JEPA predicts missing information in an abstract representation space instead of at the pixel level, which allows it to learn more detailed features without needing human-designed tricks. This approach is faster and requires less computation than other methods.

Existing methods for predicting missing parts of an image often fail to learn detailed features that work well for a wide range of tasks. Most methods focus on predicting missing pixels or tokens, which can lead to less detailed representations that require extra tuning to perform well on complex tasks. I-JEPA uses a multi-block masking strategy that focuses on predicting larger, more informative sections of the image. This helps the model learn features that are useful for both detailed and simpler tasks without needing extra tuning.

Training models to understand images without labels is often slow and computationally expensive. Other methods for predicting missing parts of an image require a lot of time and resources, especially when training large models. I-JEPA is more efficient and scalable, allowing large models to be trained in less than twelve hundred GPU hours. This makes it faster than other methods by over two point five times and more efficient by over ten times.

## The context encoder

Here is how it works. The method has five pieces: the context encoder, the target encoder, the predictor, the multi-block masking strategy and the training loop.

The context encoder processes image patches from a single context block after removing overlapping regions. It takes patches sampled with scale between zero point eight five and one and unit aspect ratio. First, it applies transformer layers with self-attention and MLPs to the masked patches. These layers generate detailed patch-level representations for the context block. The output is a representation of the masked context block, which the predictor uses as input. This step extracts meaningful features from the visible parts of the image, guiding the model to predict target blocks. The context encoder uses a Vision Transformer architecture, similar to the predictor and target encoder. It focuses on informative, sparse regions of the image to make prediction efficient.

## The target encoder

The target encoder takes the full image and converts it into a sequence of non-overlapping patches. These patches are then processed through a Vision Transformer to get patch-level representations. Next, it applies masking to select specific target blocks from these representations. The target encoder uses an exponential moving average of the context encoder's weights to update its own parameters during training. This ensures the target representations stay aligned with the context encoder's evolving outputs. The target blocks are chosen randomly, with sizes and positions varying to ensure diversity. Typically, four target blocks are selected per image, each with a random aspect ratio and scale. The target encoder's outputs serve as the targets for the predictor, which tries to match them. This setup helps the model learn rich, meaningful features without relying on human-designed tricks. The exponential moving average decay rate is set to zero point nine nine nine nine, making the target encoder's updates very smooth and stable.

## The predictor

The predictor takes the context encoder's output and mask tokens for each target block as input. It uses a narrow ViT architecture, which includes self-attention and MLP layers, to process this information. For each of the M target blocks, the predictor runs separately, conditioning on the specific mask tokens that indicate where the target blocks are located. These mask tokens are learnable vectors with positional embeddings that tell the predictor which parts of the image to focus on. The predictor then generates predictions for each patch within the target block's region. Each target block has its own set of mask tokens, and the predictor uses them to guide its predictions. The output is a set of predicted representations, one for each patch in the target block. These predicted representations are compared to the actual target block representations using a loss function that measures how close the predicted values are to the true values. The predictor is trained to minimize this loss, ensuring that it learns to accurately represent the target blocks based on the context provided. The process uses four target blocks per image, with each block having three to four patches. The predictor runs separately for each of these blocks, using their specific mask tokens to generate predictions.

## The multi-block masking strategy

The multi-block masking strategy starts by picking one context block from the image. This block is larger, with a scale between eighty-five and one hundred percent of the full image and a square shape. Then, four target blocks are randomly chosen. Each has a smaller scale, between fifteen and twenty percent, and a slightly irregular shape, with aspect ratios between seventy-five and one hundred and fifty percent. Any target block that overlaps with the context block is removed to keep the prediction task meaningful. For each target block, a mask token is created. These tokens are learnable vectors with added positional information to show where the block is in the image. The target blocks are not taken directly from the image but from the output of the target encoder. This ensures the predictions are based on higher-level, more abstract features. The mask tokens and the target encoder's outputs guide the predictor to generate representations that match the target blocks. This process focuses the model on learning rich, semantic features rather than low-level details.

## The training loop

The training loop starts by comparing the predicted target block representations with the actual ones from the target encoder. The loss is the average distance between them, measured using a two-point five loss function. This tells the model how far apart each predicted patch is from the real one. This loss guides the model to adjust its predictions to match the targets more closely.

Next, gradients from this loss are backpropagated to update the context encoder and the predictor. This step fine-tunes the model so it can better extract useful features from the context blocks and generate more accurate predictions.

At the same time, the target encoder’s weights are updated using an exponential moving average of the context encoder’s parameters. This happens at each training step, with a decay rate of zero point nine nine nine nine. This ensures the target encoder stays aligned with the context encoder but doesn’t change too quickly, which helps the model learn stable, high-level representations.

The multi-block masking strategy determines which parts of the image are used as context and which are predicted. Typically, one context block is used, and three to four target blocks are predicted. This setup ensures the model learns features that are useful for both detailed and simpler tasks without needing extra tuning.

The training loop runs repeatedly, adjusting the model’s parameters to minimize the loss. Over time, the model becomes better at predicting the target blocks from the context, leading to improved contextual and target representation capabilities.
