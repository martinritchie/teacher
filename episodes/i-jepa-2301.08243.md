This paper demonstrates an approach for learning highly semantic image representations without relying on hand crafted data augmentations. We introduce the Imagebased Joint Embedding Predictive Architecture, a non generative approach for self supervised learning from images. The idea behind Imagebased Joint Embedding Predictive Architecture is simple from a single context block predict the representations of various target blocks in the same image. A core design choice to guide Imagebased Joint Embedding Predictive Architecture towards producing semantic representations is the masking strategy specifically it is crucial to sample target blocks with sufficiently large scale semantic and to use a sufficiently informative spatially distributed context block. Empirically when combined with Vision Transformers we find Imagebased Joint Embedding Predictive Architecture to be highly scalable. For instance we train a ViT Huge on ImageNet using sixteen A one zero zero GPUs in under seventy two hours to achieve strong downstream performance across a wide range of tasks from linear classification to object counting and depth prediction.

In self-supervised learning for images, there are two main approaches: one focuses on making the model invariant to changes in the image, like different viewpoints or lighting, and the other tries to reconstruct parts of the image that have been hidden. Both methods have their challenges. Invariance-based methods use tricks like changing the image slightly to create different views, but this can make the model biased toward certain tasks and not as flexible for others. Generative methods, which try to fill in the missing parts of an image, are more flexible but usually don’t learn as high-level or meaningful features as the invariance methods. Both approaches also often rely on hand-crafted changes to the image, which can be limiting.

Current methods for learning image representations either rely on hand-crafted changes to the image or struggle to learn high-level features without them. Invariance-based methods use hand-crafted image transformations to create different views, but this can introduce biases that limit their usefulness for different tasks. Generative methods try to reconstruct parts of the image but often end up learning lower-level features that aren’t as meaningful. The authors introduce I-JEPA, a method that learns high-level image features without using any hand-crafted transformations. Instead of predicting pixels, I-JEPA predicts abstract representations, which helps the model focus on more meaningful patterns in the image.

Existing methods for self-supervised learning often struggle to scale efficiently or require complex setups to achieve good results. Many methods require a lot of computational power and time, especially when training large models. Some methods also need extensive tuning or additional steps to adapt to new tasks. I-JEPA is more efficient and easier to scale. The authors show that training a large Vision Transformer model on ImageNet using I-JEPA takes less than seventy-two hours with sixteen A one zero zero GPUs, which is much faster than other methods like MAE or iBOT.

Current approaches for learning image representations often focus on either specific tasks or specific types of features, limiting their versatility. Invariance-based methods are good for some tasks like image classification but not others like depth prediction or object counting. Generative methods, while more flexible, often don’t learn the right level of detail for these tasks without extra tuning. I-JEPA learns representations that are useful across a wide range of tasks, from high-level classification to low-level tasks like depth prediction. It achieves this by using a simple architecture that doesn’t rely on rigid assumptions about the data, making it more adaptable.

Here is how it works. The method has seven pieces: the context encoder, the target encoder, the predictor, the masking strategy, the loss function, the exponential moving average and the training loop.

The context encoder processes a single block of visible image patches. It takes a block sampled from the image with a scale between eighty five and one hundred percent and a unit aspect ratio. It runs a Vision Transformer on this block to generate contextual embeddings. These embeddings capture spatial relationships within the block. The encoder outputs these embeddings, which the predictor later uses to make predictions. The context block is chosen to be informative but sparse, ensuring it's efficient to process. Any overlapping regions with target blocks are removed to make the prediction task meaningful. The encoder's output is a set of patch-level representations that guide the predictor in estimating the target blocks' representations.

The target encoder processes the full input image using a Vision Transformer, stacking layers of self-attention and MLPs. It generates a sequence of patch-level representations for every patch in the image, whether visible or masked. These representations form the basis for the prediction task. From this full sequence, we randomly sample four target blocks. Each block has a scale between fifteen and twenty percent of the image and an aspect ratio between seventy five and one hundred fifty percent. These blocks are chosen to capture large-scale semantic content. The encoder’s output includes all patch-level representations, and the sampled blocks are used as targets during training. This ensures the predictor learns meaningful, high-level features from the full set of representations.

The predictor takes the context encoder’s output and mask tokens to generate predicted representations for each target block. It starts by taking the contextual embeddings from the visible block processed by the context encoder. Then it combines these with mask tokens that carry positional information for each target block patch. These mask tokens are learnable vectors with added positional embeddings, indicating where each patch in the target block is located. Next, a Vision Transformer processes this combined input to generate predicted representations for every patch in the target block. The predictor runs this process separately for each of the four target blocks, using the mask tokens specific to each patch in the block. The output is predicted representations for all four target blocks, each containing multiple patches. The predicted values are compared to the actual target block representations using a distance metric that measures how far apart the predicted and real representations are. This loss guides the predictor to refine its predictions during training. The predictor is trained alongside the context encoder, while the target encoder is updated using an exponential moving average of the context encoder’s parameters.

The masking strategy defines how target and context blocks are sampled to ensure meaningful prediction. Starting with the input image, it first samples four target blocks, each with a scale between fifteen and twenty percent of the image and an aspect ratio between seventy five and fifteen percent. These blocks are chosen to capture large-scale semantic content. Then, it samples a single context block with a scale between eighty five and one hundred percent and a unit aspect ratio, ensuring it's informative but not too dense. Any overlapping regions between the context block and the target blocks are removed to make the prediction task non-trivial. The positions of these blocks are then passed to the target encoder and context encoder for processing. This strategy ensures that the model learns to predict high-level semantic features from sparse, meaningful context, improving efficiency and scalability.

The loss function measures how well the predictor matches the actual target block representations. It starts by calculating the distance between predicted and actual patch-level representations for each target block. This means squaring the difference between each predicted and actual value, then adding them up for all patches in the block. Next, it averages these summed distances across all four target blocks to get a single loss value. This scalar loss guides the model by telling it how far off its predictions are. The loss uses a distance metric that emphasizes larger errors more than smaller ones. The loss is used to update the context encoder’s parameters during training, helping the model improve its ability to predict semantic representations from context blocks.

The exponential moving average keeps the target encoder slightly behind the context encoder to stabilize training. At each step, it updates the target encoder parameters using a weighted average of the current context encoder parameters. The weight is determined by a decay factor, which ensures the target encoder doesn’t change too quickly. This decay factor is usually set to a value close to one, like ninety nine percent or ninety nine point nine percent, so the target encoder slowly adapts. The context encoder parameters are updated first through the loss, and then the target encoder follows using this moving average. This setup helps the model learn more consistent representations by reducing fluctuations in the target encoder. The exponential moving average is crucial for training with Vision Transformers, as it prevents instability during updates.

The training loop starts by sampling context and target blocks using the masking strategy. The context block is a single region of the image with uniform aspect ratio and scale, chosen to be informative. The target blocks are four regions with larger semantic content, sampled with random aspect ratios and scales. Next, the context encoder processes the visible patches in the context block to generate contextual embeddings. The target encoder then generates patch-level representations for the entire image, including both visible and masked regions. The predictor takes the contextual embeddings and mask tokens, which indicate where the target blocks are, to predict their representations. These mask tokens are learnable vectors with positional embeddings, generated separately for each patch in the target blocks. The loss is calculated as the average L2 distance between the predicted and actual target block representations. This loss guides the context encoder's parameter updates through gradient descent. Meanwhile, the target encoder's parameters are updated using an exponential moving average of the context encoder's weights. This sequence repeats, allowing the model to iteratively refine its ability to predict semantic representations from context blocks. The process ensures the model learns high-level features without relying on hand-crafted transformations.
